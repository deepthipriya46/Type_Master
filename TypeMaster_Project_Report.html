03 Key Features & Systems Built Till Now
⚡ 1. Real-Time Typing Engine
  • Real-time WPM Calculation: Computed dynamically using standard character formula: (chars / 5) / (seconds / 60).
  • Raw vs. Net WPM: Accurately isolates gross keystroke speed versus penalized uncorrected errors.
  • Smooth Caret & Live Highlighting: Character-by-character feedback (green for correct, red for incorrect, pulsing active cursor).
  • Configurable Test Modes: Durations of 1m, 3m, 5m, and Custom; Easy, Medium, and Hard difficulties.
🎹 2. Acoustic & Virtual Keyboard
  • Procedural Sound Synthesizer: Zero-dependency Web Audio API implementation with 4 tactile switch modes (Cherry Blue, Cherry Red, Brown, Typewriter).
  • Interactive Virtual Keyboard: Real-time keypress highlighting on visual QWERTY keyboard with home-row finger indicators.
  • Audio Feedback: Auditory error buzzer on mistakes and 4-note ascending celebratory chime upon test completion.
🛡️ 3. Anti-Cheat & Verification Service
  • Duration Threshold Check: Rejects tests terminated in < 3 seconds to prevent stat dilution.
  • Human Feasibility Limit: Flags and rejects any anomaly exceeding human physiological limits (> 250 WPM).
  • Character Ratio Sanity: Validates reported character counts against time elapsed.
  • Automated Grading: Awards performance badges (Needs Practice, Good, Great, Excellent).
📊 4. Telemetry & Analytics Dashboard
  • 5 Real-Time Stat Cards: Best WPM, Average WPM, Overall Accuracy, Tests Completed, Day Streak.
  • Dynamic SVG Trend Charts: Plots historical test sessions without third-party chart dependencies.
  • Streak Engine: Automatically calculates consecutive active practice days and longest streaks.
  • Test Logs History: Real-time session ledger with detailed drill-down modal.
04 Database Schema & Cloud Persistence

A complete production-grade relational database schema was authored in supabase_schema.sql, featuring full Row Level Security (RLS) policies and dual-mode runtime compatibility:

Table Name Primary Key Core Columns / Metrics Tracked Security & Policies
users id (TEXT) username, email, best_wpm, avg_wpm, accuracy, tests_completed, is_premium RLS enabled; authenticated read/write
test_logs id (UUID) user_id, wpm, raw_wpm, accuracy, duration, errors, category, difficulty, badge RLS enabled; cascade delete on user removal
streaks id (UUID) user_id, current_streak, longest_streak, last_active_date, updated_at RLS enabled; daily timestamp tracking
achievements (id, user_id) title, description, icon, unlocked (boolean), unlocked_at RLS enabled; dynamic trigger checks
prompts id (UUID) category, difficulty, text, word_count, created_at Public read; categorized seed library
Dual-Engine Architecture: The application incorporates an embedded local engine fallback. If Supabase cloud credentials are not yet entered, TypeMaster transparently persists all live metrics to browser storage and allows immediate full testing without blocking the user. When Supabase keys are connected via the in-app modal, the app seamlessly integrates with the remote PostgreSQL instance.
