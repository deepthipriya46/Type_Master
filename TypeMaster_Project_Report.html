01 Executive Project Summary

03 Frontend Engineering: Completed Work & Components

The frontend is constructed using modular, reusable React 19 components without bulky third-party UI component libraries, guaranteeing lightweight bundle size, instantaneous render cycles, and custom visual polish.

⚡ 1. Real-Time Typing Arena & Caret Engine

  • Pulsing Active Caret: Smooth, non-distracting cursor positioned dynamically ahead of the active character.

  • Ergonomic Finger-Zone Indicators: Color-coded key groups mapping keys to Pinky, Ring, Middle, and Index finger zones for touch-typing practice.
  • Error State Animation: Instant amber/red flashes on mistake strokes to reinforce muscle memory.
📊 3. Telemetry Visualizer (`AnalyticsCharts.jsx`)
  • Dependency-Free SVG Vector Charts: Smooth Bezier curve interpolations plotting historical WPM and accuracy progression over time.
  • Dynamic Point Tooltips: Interactive hover states displaying exact WPM, accuracy %, test date, and duration for every session.
  • Zero External Chart Libraries: Eliminates chart bloat (no Chart.js or Recharts), yielding near-instant initial bundle loading.
🎨 4. Design System & Theme Engine (`index.css`)
  • 33KB Curated CSS Architecture: Built on CSS variables/tokens for colors, radiuses, shadows, and glassmorphic elevations.
  • 4 Complete Color Themes: Dark Pro (Default sleek navy), Cyberpunk Neon (high-contrast magenta/cyan), Matrix Green, and Slate Studio.

05 Backend & Business Logic Systems

The backend layer comprises autonomous JavaScript service modules handling sound generation, anti-cheat validation, PDF text extraction, and cloud/local persistence orchestration:

🔊 1. Procedural Web Audio Engine (`soundSynthesizer.js`)
  • Zero Audio Assets Required: Procedurally generates mechanical sound waves using the browser's native Web Audio API (`AudioContext`). Zero network lag and 0ms latency.
  • 4 Tactile Switch Emulation Profiles:
    • Cherry MX Blue: Sharp dual-click high-frequency detent (2800 Hz transient + 1400 Hz pop).
    • Cherry MX Red: Smooth linear clack with dampened low-frequency bottom-out (450 Hz).
    • Cherry MX Brown: Subtle tactile resistance bump with medium frequency profile.
    • Vintage Typewriter: Heavy metallic strike with longer resonant mechanical decay.
  • Harmonic Completion Chimes: Produces a 4-chord ascending celebration sequence (C5-E5-G5-C6) upon completing tests, plus error buzzers on typos.
🛡️ 2. Anti-Cheat & Telemetry Validation (`antiCheatService.js`)
  • Minimum Duration Threshold: Discards and rejects tests under 3 seconds to prevent stat inflation or accidental trigger submissions.
  • Physiological Typing Speed Ceiling: Flags and disallows anomalous submissions exceeding human capability (>250 WPM) to stop automated bot scripts.
  • Keystroke Sanity Ratio Check: Cross-examines total logged characters against active duration to detect synthetic batch injections.
  • Smart Grade Classification: Automatically grades verified tests (Needs Practice, Fair, Good, Great, Excellent, Master). Low-speed high-accuracy tests correctly receive "Fair" rather than "Invalid".
📚 3. PDF Word Repository Parser (`pdfTextLoader.js`)
  • Asynchronous PDF Extraction: Utilizes `pdfjs-dist` to dynamically parse passages from `words_repository.pdf` in the client.
  • Text Normalization & Noise Cleaning: Strips publishing headers, ISBNs, book watermarks, website references, and hyphenated line-breaks.
  • In-Memory Cache (230KB Word Bank): Pre-caches 600+ vetted, grammatically coherent sentences from `pdfPassages.js` on app load (`main.jsx`) for 0ms instantaneous access.
  • Intelligent Duration-Based Slicing:
    • 15s / 30s / 1m: ~50-80 words
    • 3m: ~180-250 words
    • 5m: ~350-500 words
    • Custom: ~600+ words
🔄 4. Dual-Engine Persistence Orchestrator (`supabaseService.js`)
  • Universal Data Abstraction Layer: 86KB module abstracting user state, test submission, streak updates, and achievement unlocks.
  • Zero-Friction Local Mode: Automatically functions in guest/offline mode when cloud keys are unset, persisting full history to browser storage.
  • Cloud Supabase Mode: Seamlessly communicates with Supabase PostgreSQL via `@supabase/supabase-js` upon user login or API key input.
  • Real-Time Streak & Achievement Engines: Evaluates consecutive practice calendar days and unlocks milestone trophies dynamically upon test completion.
06 Engineering Refinements & Bug Resolves

Key operational refinements implemented across recent iterations to guarantee stability and usability:

Area / Module Problem Addressed Engineering Solution Applied
"New Text" Button & Dynamic Slicing Button click was not rotating the test text prompt dynamically and left typing counters in stale states. Wired `getPassageForDuration()` with duration-aware word sizing; complete reset of input buffers, timer, and keyboard highlights.
Test Result Tagging ("Invalid" Bug) Typing slowly (e.g. 12 WPM) with 100% accuracy was incorrectly tagged as "? Invalid". Revised grading rubric: low-speed submissions with high accuracy are classified as "Fair"; "Invalid" is strictly reserved for cheat violations.
CSV Export File Format Exporting test history downloaded an extensionless UUID file that could not be opened directly in Excel. Wrapped data in UTF-8 text/csv Blob and enforced explicit filename attribute: `TypeMaster_Test_History.csv`.
Offline Passages Cold Start Remote prompt loading introduced network latency before a user could start typing. Integrated pre-compiled `pdfPassages.js` sentence bank (230KB) initialized at application boot in `main.jsx`.

07 Database Architecture & Supabase Schema

The database backend is structured in PostgreSQL via Supabase, codified in supabase_schema.sql. It features strict relational integrity, UUID primary keys, and comprehensive Row Level Security (RLS) policies.

Table Name Primary Key Columns & Data Types Tracked Security & Constraints
users id (TEXT) email (TEXT), username (TEXT), avatar_url (TEXT), best_wpm (INTEGER), avg_wpm (NUMERIC 5,2), accuracy (NUMERIC 5,2), tests_completed (INTEGER), is_premium (BOOLEAN), created_at, updated_at RLS enabled; public and authenticated SELECT, INSERT, and UPDATE policies.
test_logs id (UUID) user_id (TEXT, FK), wpm (INTEGER), raw_wpm (INTEGER), accuracy (NUMERIC 5,2), duration (INTEGER), errors (INTEGER), characters (INTEGER), category (TEXT), difficulty (TEXT), result_badge (TEXT), is_valid (BOOLEAN), created_at RLS enabled; Foreign Key to users(id) with ON DELETE CASCADE; indexed on user_id.
streaks id (UUID) user_id (TEXT, FK, UNIQUE), current_streak (INTEGER), longest_streak (INTEGER), last_active_date (DATE), updated_at (TIMESTAMP) RLS enabled; UNIQUE constraint on user_id ensures single streak record per typist.
achievements (id, user_id) id (TEXT), user_id (TEXT, FK), title (TEXT), description (TEXT), icon (TEXT), unlocked (BOOLEAN), unlocked_at (TIMESTAMP) RLS enabled; composite PK; Foreign Key to users(id) ON DELETE CASCADE.
prompts id (UUID) category (TEXT), difficulty (TEXT), text (TEXT), word_count (INTEGER), target_duration (TEXT), created_at (TIMESTAMP) RLS enabled; public read policy; seeded with initial categorized typing prompts.
Row Level Security (RLS) Implementation: Every table in the TypeMaster schema enforces RLS. Security policies grant authorized reading, inserting, and updating of personal test metrics while safeguarding other typists' data. Cascading deletions (`ON DELETE CASCADE`) guarantee zero orphaned telemetry records.

09 Database Schema SQL Specification
-- Excerpt from supabase_schema.sql
CREATE TABLE IF NOT EXISTS public.test_logs (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  user_id TEXT NOT NULL REFERENCES public.users(id) ON DELETE CASCADE,
  wpm INTEGER NOT NULL, raw_wpm INTEGER NOT NULL,
  accuracy NUMERIC(5,2) NOT NULL, duration INTEGER NOT NULL,
  errors INTEGER NOT NULL DEFAULT 0, characters INTEGER NOT NULL DEFAULT 0,
  category TEXT DEFAULT 'Random Text', result_badge TEXT DEFAULT 'Good',
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
